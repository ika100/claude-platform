# Backlog

User stories for this repo. Every feature starts here: run `/svc:plan-feature <description>` to have the product-manager add stories and the architect write the plan in `docs/plan/<slug>.md`, review both, then build with `/svc:build-feature --plan docs/plan/<slug>.md`.

Story format (the product-manager agent writes and updates it):

```markdown
#### STORY-001 — <title>
**Status:** open | in progress | done · **Priority:** P0 | P1 | P2 · **Tracks:** #<issue> (optional)

As a <persona>, I want <goal>, so that <benefit>.

**Acceptance criteria:**
- [ ] <testable criterion>
```
